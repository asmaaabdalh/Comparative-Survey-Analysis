# Java, Python & R Survey — Data Analysis & Power BI Dashboard

This repository contains the **data analysis and interactive Power BI dashboard** component of a survey study examining the usage of **Java, Python, and R** among students and tech professionals.

## Scope of Work

This part focuses on transforming raw survey responses into structured insights and an interactive visual report:

- **Data Cleaning & Preprocessing:** Filtered and standardized raw survey responses (resulting in **177 valid responses**), handled missing or inconsistent entries, and prepared variables for analysis.
- **Exploratory & Comparative Analysis:**
  - Examined participant demographics (students vs. tech professionals).
  - Compared adoption and usage patterns across **Java, Python, and R**.
  - Extracted bilingual NLP insights from open-ended responses.
- **Power BI Dashboard:** Built a data model, DAX measures/KPIs, and interactive visuals to compare trends across languages and respondent groups.


> Note: This repository presents only the data analysis and Power BI dashboard work, not the full multi-part project.

## Highlights

- Summary KPIs and respondent overview (**177 valid responses**).
- Side-by-side comparison of **Java, Python, and R** usage.
- Interactive slicers for filtering by respondent background and language.
